id: screen-recording
title: Grant AeroSpace Screen Recording
when: 'os = "macos"'
after: install
revision: 1
---

AeroSpace needs Screen Recording for the `screencapture` keybindings (Cmd+S, Cmd+Shift+S):

System Settings > Privacy & Security > Screen Recording > enable **AeroSpace**.

Also launch it once (`open -a AeroSpace`) so it registers its login item.
