---
id: disable-secure-input
title: Turn off Secure Keyboard Entry in Ghostty
when: 'os = "macos"'
after: install
revision: 1
---

Ghostty's Secure Keyboard Entry blocks tools that watch the keyboard (Karabiner, LinearMouse
shortcuts, text expanders).

1. Open Ghostty, then the menu bar item **Ghostty**.
2. Untick **Secure Keyboard Entry**.

Verify: the menu item has no check mark, and Karabiner remaps work inside Ghostty.
